# Contributing

Use issues and pull requests for improvements. Run `npm ci`, `npm test` and
`npm run test:package` on Node.js 22 or newer before submitting a change.

Use synthetic examples. Do not commit credentials, cookies, source URIs,
customer data, generated archives or node_modules. Public tool request contracts
are a coordinated upstream snapshot; update their TypeScript and JSON schemas
together. Do not weaken confirmation, authorization, snapshot or retry boundaries.

Client tests do not replace server-side authorization or integration qualification.
